# 0003 — Xóa `poc/`

- **Trạng thái:** Chấp nhận (06/11/2026)
- **Bối cảnh:** `poc/` chỉ còn README (mã PoC chưa từng được chép vào repo); giai đoạn 1 viết lại `chatcore` theo spec và đã tái hiện các kết quả PoC bằng test.
- **Quyết định:** xóa `poc/`, bỏ khỏi bố cục trong quy ước tổ chức. Đổi ADR 0001 ở điểm "`poc/` đóng băng rồi xóa sau bước 1" thành đã thực hiện sớm.
- **Hệ quả:** kết quả PoC chỉ còn trong spec mục 8. Mã PoC gốc (ngoài repo) nếu cần giữ thì lưu riêng.
